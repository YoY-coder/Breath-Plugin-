## Nouveautés de la V0.3
- **Automation** : sur chaque piste, des emplacements « Self » + 8 sources, nommés d'après la piste source
  (« Kick – Quantité », « Kick – Seuil »). **Quantité** et **seuil global** (décalage de −24 à +24 dB de toute la
  courbe de seuil) sont automatisables.
- **Tilt** façon Soothe : Détail, Attaque et Release ont chacun deux petites cases **bas | haut** à régler en
  glissant ↕ (attaque / release : ×0,1 à ×10 ; double-clic = neutre).
- **Stéréo** : mode **L/R** ou **M/S**, **Link** (100 % = même réduction sur les deux voies) et **Focus**
  (part de chaque voie, ex. « M 53 · S 100 »).
- **Affectations** : petite **croix** sur chaque pastille pour la retirer ; clic droit = bypass, menu sous la pastille.
  Une **nouvelle instance démarre en Self** (anti-résonances, seuil auto).
- **Graphique** : étiquette max à gauche, seuil à droite, poignée du knee à droite ; **Ctrl + glisser** sur un point
  = largeur ; **Shift = réglage fin partout** ; en **Hard**, −70 dB tout en bas du graphe.
- **Attaque jusqu'à 300 ms** (défaut inchangé : 5 ms). **64 | 128 bandes** à côté de Soft | Hard.
- **Noms de piste** : le nom n'est plus effacé quand Ableton n'envoie que la couleur.
- Correction : la conversion des anciens projets se déclenche correctement.

## Compatibilité
Les projets V0.1 / V0.2 se rouvrent avec le même son : l'ancien « Stéréo / Mid / Side » est converti en
L/R ou M/S + Focus équivalent, les tilts sont neutres, les Quantités sont recopiées dans les emplacements d'automation.

## Installation
- **Windows** : dézipper `Breath-V0.3-Windows.zip`, copier `Breath.vst3` dans `C:\Program Files\Common Files\VST3\`.
- **Mac** : dézipper `Breath-V0.3-macOS.zip`, copier `Breath.vst3` dans `~/Library/Audio/Plug-Ins/VST3/`, puis dans le Terminal :
  `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Breath.vst3`
