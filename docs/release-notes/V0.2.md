## Nouveautés de la V0.2
- **Courbe de seuil façonnable**, comme la courbe max : double-clic sur la courbe pointillée du seuil = ajouter
  un point ; glisser = fréquence / niveau ; molette = largeur ; double-clic ou clic droit sur un point = supprimer.
  Double-clic sur la poignée ronde centrale = seuil par défaut.
- **Seuil « soft » (knee)** : poignée ≡ près du bord gauche de la zone, à glisser vers le haut pour élargir le knee
  (0 à 24 dB). La bande colorée autour du seuil montre la zone où la réduction démarre en douceur.
  Double-clic sur la poignée = knee à 0 (seuil dur).

Les projets V0.1 se rouvrent à l'identique (knee à 0, aucun point de seuil) : **pas de changement de son**.

## Installation
- **Windows** : dézipper `Breath-V0.2-Windows.zip`, copier `Breath.vst3` dans `C:\Program Files\Common Files\VST3\`.
- **Mac** : dézipper `Breath-V0.2-macOS.zip`, copier `Breath.vst3` dans `~/Library/Audio/Plug-Ins/VST3/`, puis dans le Terminal :
  `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Breath.vst3`
