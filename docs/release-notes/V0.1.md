Première version numérotée de Breath.

## Installation
- **Windows** : dézipper `Breath-V0.1-Windows.zip`, copier `Breath.vst3` dans `C:\Program Files\Common Files\VST3\`.
- **Mac** : dézipper `Breath-V0.1-macOS.zip`, copier `Breath.vst3` dans `~/Library/Audio/Plug-Ins/VST3/`, puis dans le Terminal :
  `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Breath.vst3`
